# SnapCam

**A professional camera app for Android** — built with Kotlin, Jetpack Compose, CameraX, and OpenGL.

## Features

- 📸 **Photo & Video capture** — front/back camera, flash, zoom, tap-to-focus, timer
- 🎨 **40+ real-time color filters** — including 7 iPhone-style LUT filters (Vivid, Natural, Rich, Clean, Airy, Amber, Cool), plus custom `.cube` LUT import
- 🕌 **Islamic audio presets for tilawat/naat** — Masjid Reverb, Haram Echo, Warm Qari, Studio Clear, Soft Dua, and more (reverb/EQ-based, no pitch distortion)
- 💄 **Beauty controls** — smoothing, brightness, contrast, saturation sliders
- ⚡ **Optimized for all devices** — from budget phones (Redmi series) to flagships (Galaxy S24 Ultra)

## Tech Stack

- Kotlin + Jetpack Compose
- CameraX (preview, photo, video)
- OpenGL ES (real-time filter rendering)
- MVVM architecture

## Setup

1. Clone the repo
2. Open in Android Studio
3. Connect a physical Android device (API 26+)
4. Run
